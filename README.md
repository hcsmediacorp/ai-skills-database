# AI Skills Database

A production-ready Next.js application for publishing and discovering markdown-formatted skill files. Skills are indexed in Supabase Postgres, stored as public `.md` files in Supabase Storage, searchable through a polished UI, downloadable by humans, and fetchable by AI models through raw public URLs.

## Features

- Public homepage with hero, debounced search, tag filters, and responsive skill cards
- Skill detail pages with metadata, download button, raw URL button, and markdown preview
- Anonymous upload form with drag-and-drop `.md` upload, 500KB limit, validation, slug generation, and collision handling
- API routes for listing, fetching, and uploading skills
- Supabase Postgres table plus public Storage bucket
- 50 premium seed skills generated by `scripts/seed.ts`
- Dark mode, sticky navigation, mobile menu, accessible labels, focus rings, and SEO metadata

## Tech Stack

Next.js 14 App Router, TypeScript strict mode, Tailwind CSS, shadcn/ui-style components, next-themes, Supabase PostgreSQL, Supabase Storage, Vercel.

## Getting Started

```bash
npm install
cp .env.example .env.local
npm run dev
```

Create the Supabase table and public bucket before running the app against real data. See `DEPLOYMENT.md` for exact setup steps.

## Environment Variables

```bash
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
```

`SUPABASE_SERVICE_ROLE_KEY` is used only in server-side route handlers and the seed script. Never expose it to client components.

## Seed Data

```bash
npm run seed
```

The seed command uploads 50 markdown files to the public `skills` bucket and upserts matching metadata into the `skills` table.

## API

- `GET /api/skills?q=&tag=` — list searchable skills
- `GET /api/skills/[slug]` — fetch metadata and markdown preview for one skill
- `POST /api/skills/upload` — multipart form upload with `title`, `description`, `tags`, and `file`
